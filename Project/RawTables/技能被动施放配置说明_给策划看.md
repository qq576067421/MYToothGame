# 技能被动施放配置说明（t_skill_cast_style = 2）

更新日期：2026-11-16

适用范围：
- `Project/RawTables`（源表）
- `Project/public/Tables`（导出表）

涉及 sheet：
- `jn 技能表.xlsx` → `t_skillBean`
- `jn 技能描述表.xlsx` → `t_skillDescBean`
- `t_actionBean`（动作表，可在导出的 `t_actionBean.csv` 里核对）

本文只讲“策划怎么配”，不讲程序实现。

## 1. 一句话语义

`t_skill_cast_style`：

- `0` 手动施放（玩家点击）
- `1` 自动施放（自动选技循环接管）
- `2` **被动施放**：冷却一到就自己放，**不打断角色当前行为**

被动施放的具体含义：

- 不切换角色状态，不打断正在释放的其他技能、不打断普攻、不打断移动
- 不改变角色朝向
- **不播角色自身的攻击动作**（所以没有动作表现，靠音效和特效给反馈）
- 照常结算：前置条件消耗、施法 buff、攻击音效、技能特效、发弹、伤害、冷却

现有配置全部是 0 / 1，改动前已上线的行为完全不变；只有明确填 2 的槽位才会走被动通道。

## 2. 触发规则

被动技能自己发动，不需要也不会响应任何输入：

| 规则 | 说明 |
|---|---|
| 触发条件 | 冷却结束的那一刻自动发动 |
| 冷却起点 | 从**发动瞬间**开始计时，不是伤害结算时刻 |
| 施法者状态 | 必须存活、未被控制（冰冻/眩晕）、未被挂起、未被沉默 |
| 战斗阶段 | 塔防中升级挑战的倒计时与挑战过程中不发动，回到正常战斗后恢复 |
| 手操 | 点击该槽位没有任何反应，不切状态、不出弹 |
| 自动循环 | 自动选技不会选它，不会因为它去打断普攻 |
| 中途打断 | 角色被控/死亡时本次被动立刻中断，未结算的伤害不会补发 |
| 朝向 | 有合法目标就朝目标出手，没有就按角色当前面向；两种情况都不会把角色转过去 |

## 3. 必配字段

### 3.1 `t_skillBean`（jn 技能表）

| 字段 | 配置要求 |
|---|---|
| `t_skill_cast_style` | 填 `2` |
| `t_cooldown` | **必须大于 0**。填 0 时冷却只剩 1 毫秒，表现成“上一次施法一结束就立刻接下一次”，形成不间断连发 |
| `t_bullet_id` | 需要发子弹就必配；纯加 buff / 纯直接伤害可以留空 |
| `t_hurt_param_type` / `t_hurt_param0` / `t_hurt_param1` | 直接命中判定用的范围参数（0 落点圆 / 1 矩形 / 2 施法者周围 / 3 扇形），发子弹的技能按子弹判定即可 |
| `t_keep_time` + `t_hurt_interval` | 两个都填 > 0 才是“持续型被动”（见模板 C）。只填其中一个按单次施法处理 |
| `t_skill_precon` | 可选。格式 `条件buff+层数+是否清空(0清空 1不清空)`，例如 `921002+3+1` = 要有 3 层 921002 |
| `t_skill_selfbuff_id` | 可选。施法点给自己上的 buff，被动同样生效 |
| `t_summon` | 被动不支持，见 3.4 |

### 3.2 `t_skillDescBean`（jn 技能描述表）—— 决定“什么时候出伤害”

| 字段 | 配置要求 |
|---|---|
| `t_action` | **必配且要算过**。被动沿用动作表的时间轴来决定生效时点：**生效时刻 = `t_ac_cast_point` ÷ `t_frame_rate`（秒）** |
| `t_attackSound` | 发动瞬间播，强烈建议配。被动没有动作，音效是主要反馈 |
| `t_atk_eff` / `t_atk_eff_pos` / `t_atk_eff_parent` | 技能特效，发动瞬间播，强烈建议配 |
| `t_atk_cast_eff` / `t_atk_cast_eff_pos` / `t_atk_cast_eff_parent` | 生效点特效，在真正出伤害/出弹的那一帧播 |
| `t_hitSound` / `t_hitEff` | 命中表现，跟随命中结算，照常生效 |
| `t_keepSound` | 持续型被动的循环音效 |

`t_action` 的兜底规则要注意：

- 留空，或填了 `t_actionBean` 里不存在的 id → 退回内置 `attack`（20 帧 @30fps），**生效时刻变成约 0.67 秒**
- 可用参考（现有动作表真实数据）：

| 动作 id | 生效帧 / 帧率 | 生效时刻 |
|---|---|---|
| `110_attack` | 2 / 20 | 0.10 秒 |
| `130_attack` | 12 / 20 | 0.60 秒 |
| `130_special_attack` | 12 / 20 | 0.60 秒 |
| `200_boss` | 20 / 30 | 0.67 秒 |
| 未配 / 配错 | 20 / 30（兜底） | 0.67 秒 |

被动不播动作，所以 `t_action` 在这里配的是“时间轴”，不是“动画”。

### 3.3 配了也不生效 / 不用配的字段

| 字段 | 说明 |
|---|---|
| `t_change_attack`（释放技能是否打断当前状态切 attack） | 被动永远不打断，填 0 或 1 都一样 |
| `t_finish_change_idle`（结束是否切 idle） | 被动不碰状态机 |
| `t_upper_rot_params`（上半身转动角度+缓动） | 被动不动骨骼，填了不生效。要表现请走 `t_atk_eff` |
| `t_warning`（预警圈） | 被动不播预警，填了不生效 |
| `t_skill_op_type` / `t_skill_op_radius` / `t_skill_op_deg` | 手操指示器，被动用不到 |
| `t_icon` / `t_gesture` / `t_gesture_phase` | 手操与 UI 用，被动用不到 |

### 3.4 `t_summon`（分身）

`t_summon` 只对塔防 Boss 的 slot 1 生效，**被动不支持**：配成 2 的 Boss 技能不再走 Boss 自己的施法运行时（否则同一技能会被被动通道和 Boss 运行时重复释放），因此拿不到施法结算窗口与分身召唤。

需要 Boss 分身就保持 `t_skill_cast_style = 1`。

## 4. 三个可抄的配置模板

### 模板 A：周期额外一击（最常用）

定位：角色身上挂一个“每隔 X 秒补一发”的被动，不影响任何操作手感。

`t_skillBean`

| 字段 | 值 |
|---|---|
| `t_skill_cast_style` | `2` |
| `t_cooldown` | `8000`（8 秒一次，按需要调） |
| `t_bullet_id` | 该角色对应的子弹 id（当前角色 1 用 `1001`，角色 2 用 `1101`~`1103`） |
| `t_hurt_param_type` / `t_hurt_param0` | `0` / `1000` |
| `t_keep_time` / `t_hurt_interval` | `0` / `0` |
| `t_skill_precon` | `0` |

`t_skillDescBean`

| 字段 | 值 |
|---|---|
| `t_action` | `110_attack`（0.10 秒生效） |
| `t_attackSound` | 与同角色普攻一致（角色 1 是 `10`，角色 2 是 `20`） |
| `t_atk_eff` / `t_atk_eff_pos` / `t_atk_eff_parent` | 建议 `61` / `fire_point` / `0`（参考技能 134） |
| `t_upper_rot_params` | 留空 |

### 模板 B：叠层触发

定位：某个 buff 叠到 N 层才补一发，用条件做 gate，冷却只做防连发。

| 表 | 字段 | 值 |
|---|---|---|
| `t_skillBean` | `t_skill_cast_style` | `2` |
| | `t_skill_precon` | `921002+3+1`（要有 3 层 921002，且发动后不清空） |
| | `t_cooldown` | `500`~`1000`（条件持续满足时防止“一结束就立刻再接一次”，**不要填 0**） |
| `t_skillDescBean` | `t_action` | `110_attack` 或按需要的生效时点 |
| | `t_attackSound` / `t_atk_eff` | 按模板 A 配 |

### 模板 C：持续型被动（周期伤害窗口）

定位：一段固定时长的“自动扫射 / 自动喷流”，窗口内按间隔持续结算。

| 表 | 字段 | 值 |
|---|---|---|
| `t_skillBean` | `t_skill_cast_style` | `2` |
| | `t_cooldown` | `12000` |
| | `t_keep_time` | `2000`（窗口 2 秒） |
| | `t_hurt_interval` | `200`（窗口内每 0.2 秒结算一次） |
| | `t_bullet_id` | 对应子弹 |
| `t_skillDescBean` | `t_action` | `110_attack`（窗口起点 = 生效点） |
| | `t_keepSound` | 循环音效 id（持续型建议配，否则窗口内没有持续反馈） |
| | `t_atk_cast_eff` | 建议配成跟随挂点的持续特效 |

注意：`t_keep_time` 与 `t_hurt_interval` 必须**同时 > 0**，只配一个会被当成单次施法。

## 5. 配完自查清单

1. `t_skill_cast_style` 填的是 `2`，不是 `1`
2. `t_cooldown` 大于 0
3. `t_action` 填的是动作表里真实存在的 id，并按 3.2 算过生效秒数
4. 至少配了一处反馈：`t_attackSound` 或 `t_atk_eff`
5. 要发弹 → `t_bullet_id` 已配；要直接伤害 → `t_hurt_param_type` / `t_hurt_param0` / `t_hurt_param1` 已配
6. 持续型 → `t_keep_time` 与 `t_hurt_interval` 都大于 0
7. 没有把 `t_upper_rot_params` / `t_warning` 当作生效保障
8. 塔防 Boss 的 slot 1 没有填 2

## 6. 常见错配与现象对照

| 现象 | 原因 | 修法 |
|---|---|---|
| 点了槽位没反应 | 被动只自动发动，手操入口拒绝对 2 的槽位 | 正常现象，看冷却 |
| 伤害比预期晚约 0.6~0.7 秒 | `t_action` 留空或 id 写错，走了 `attack` 兜底 | 补正确的 `t_action` |
| 完全看不到表现 | 没配 `t_attackSound` 与 `t_atk_eff` | 补音效或特效 |
| 一瞬间连放很多次 | `t_cooldown` 填 0 或留空（冷却只剩 1 毫秒） | 配一个大于 0 的冷却 |
| 角色上半身不转 | 被动不动骨骼，`t_upper_rot_params` 不生效 | 用 `t_atk_eff` 做表现 |
| 角色放技能时被动没出 | 检查施法者是否被控/挂起，或处于升级挑战倒计时/挑战中 | 回到正常战斗后自动恢复 |
| 持续型被动只结算一次 | `t_keep_time` 与 `t_hurt_interval` 只配了一个 | 两个都填 > 0 |
| Boss 被动技能没有分身 | 被动不走 Boss 施法运行时 | 需要分身就改回 1 |

## 7. 当前不支持的触发方式

目前被动只有“冷却到就发动”一种触发，配合 `t_skill_precon` 可以实现“buff 叠够层才发动”。

暂不支持：血量阈值触发、受击触发、击杀触发、概率触发。这类需求需要程序另外加触发器，配置表本身表达不了。
